# Xuni (虚拟) 系统

> **完全原创的虚拟电场与音乐生成框架**
>
> 核心理念：超混沌采样点 / 流体粒子 / 光学追踪 → 虚拟电荷 → 电场能量 → 驱动物理建模合成器

## 核心创新

### 1. 超混沌流式采样 (XuniSampler)
- **不存储上亿点，而是实时生成**：yield 模式，内存 O(1)
- 超混沌 Chen 系统（双正 Lyapunov 指数）
- Lorenz-96 高维环状系统（40维大气动力学）
- Mandelbulb 3D 分形
- 4D 噪声场 + 混合模式

### 2. 水动力学采样 (XuniHydro) —— "水逻辑"
- 采样点 = 流体粒子，有质量/速度/压力/温度
- 简化 SPH（光滑粒子流体动力学）
- **蒸发**：高能粒子脱离，能量转化为场
- **凝结**：低能区域自发产生新粒子
- **涡旋**：旋度产生音乐颤音与和声缠绕
- 边界反弹：像水碰到玻璃壁

### 3. 玻璃逻辑引擎 (XuniGlass) —— "玻璃逻辑"
- 计算 = 光学系统：数据是光，函数是光学元件
- **透明性**：每个步骤留下"光迹"，完全可追溯
- **折射**：数据经过不同介质改变路径
- **反射**：输出反馈回输入，形成共振回路
- **色散**：棱镜分离数据的不同"频段"
- **共振腔**：模拟激光腔，多次反馈产生相干输出

### 4. 虚拟电场 (XuniField)
- 采样点密度 → 虚拟电荷
- 离散泊松方程松弛求解 → 电势与电场
- 能量密度：u = 0.5 · ε · |E|²

### 5. 原创音乐模型 (XuniMusic)
- 纯物理建模合成器，零依赖现成 AI
- 数字振荡器（正弦/三角/方波/锯齿）
- 粒子泛音系统：每个粒子独立频率、振幅、衰减
- 状态变量滤波器 + 梳状共鸣器
- ADSR 包络 + 3D 声像定位

## 快速开始

```bash
pip install -e .

# 命令行工具
xuni-cli sample --count 100000 --mode chaos
xuni-cli field --count 100000 --mode hydro
xuni-cli music --count 100000 --duration 5 --output music.wav
xuni-cli hydro --particles 4096 --steps 200
xuni-cli glass --resonance

# 启动 API 服务器（带手机控制面板）
xuni-api
# 打开 http://localhost:8000
```

## API 端点

| 端点 | 方法 | 说明 |
|------|------|------|
| `/` | GET | 手机响应式控制面板 |
| `/api/status` | GET | 服务状态 |
| `/api/sample/generate` | POST | 生成采样点 |
| `/api/field/compute` | POST | 计算虚拟电场 |
| `/api/music/generate` | POST | 合成音乐 (WAV) |
| `/api/music/generate_seq` | GET | 合成音乐序列 |
| `/ws/stream` | WS | WebSocket 实时流 |

## 手机遥控

直接访问服务地址即可使用。支持：
- 选择采样模式（含 hydro 水动力学）
- 调整采样点数（千万级）
- 一键生成音乐并播放
